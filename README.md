## Engineering Approach

I aim to build systems that are understandable, testable and
transparent about their limitations.

My projects emphasize reproducible evaluation, explicit
fallbacks, human oversight for consequential actions and
clear documentation.

All featured applications are portfolio prototypes rather
than production-certified systems.
